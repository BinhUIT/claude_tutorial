# Dự án: Landing Page (phong cách Cloaked.com)

Trang web giới thiệu sản phẩm/dịch vụ, dựng bằng **HTML/CSS/JS thuần** (không dùng framework, không cần build tool). Thiết kế lấy cảm hứng từ [www.cloaked.com](https://www.cloaked.com) — tối giản, hiện đại, chuyên nghiệp, tông màu ấm.

Toàn bộ quy tắc chi tiết (cấu trúc dự án, design system, quy ước code, quy trình kiểm tra) đã được tách theo chủ đề trong [.claude/rules/](.claude/rules/):

- [project-overview.md](.claude/rules/project-overview.md) — mô tả dự án, cấu trúc thư mục, stack
- [colors.md](.claude/rules/colors.md) — bảng màu
- [typography.md](.claude/rules/typography.md) — typography
- [layout-spacing.md](.claude/rules/layout-spacing.md) — layout & spacing
- [components.md](.claude/rules/components.md) — component (nav, nút, card, footer...)
- [scroll-animation.md](.claude/rules/scroll-animation.md) — animation khi scroll
- [design-principles.md](.claude/rules/design-principles.md) — nguyên tắc thiết kế chung
- [code-conventions.md](.claude/rules/code-conventions.md) — quy ước code
- [testing-workflow.md](.claude/rules/testing-workflow.md) — quy trình kiểm tra sau khi sửa
